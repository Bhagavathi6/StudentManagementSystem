# Student Management System

## Overview
A Java console-based application that manages student records using MySQL and JDBC.

## Features
- Add student records
- View all student records
- Search for a student by ID
- Update student details
- Delete student records
- Input validation and exception handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- JDBC
- MySQL
- Git and GitHub

## Database Setup
1. Install MySQL Server.
2. Create a database named `StudentManagement`.
3. Create a table named `Student` with columns for ID, name, age, course, and marks.
4. Configure your database connection settings locally in `db.properties`.

## How to Run
1. Install a compatible JDK and MySQL Server.
2. Configure MySQL Connector/J.
3. Set your database connection details in `db.properties`.
4. Configure the Java classpath to include the JDBC driver.
5. Run `Main.java` from VS Code.
